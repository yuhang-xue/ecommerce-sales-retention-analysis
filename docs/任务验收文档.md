第一版必验 A01—A28，交付一个经营概览看板、完整的波动与复购分析、5—6页报告和复现包。三页看板版本还须通过 E01—E03。

状态使用：未执行、通过、不通过、阻塞、按要求延后、部分完成。只有实际执行并有证据的项目可填“通过”。第一版不执行扩展项，不能将其填写为“通过”。未执行、阻塞和不通过均不视作完成。

验收通过条件：本版本所有必验项通过，阻断问题为0；证据能够定位到数据版本、SQL／脚本、参数和运行日志。展示层的小问题也应记录处理或明确约定，不以主观评分替代验收。

### 数值比较规则

- 行数、去重人数、订单数、主键和队列单元格唯一性必须精确一致。
- 同口径固定精度金额核对须精确一致。涉及 Python 浮点或 Shapley 算法时，未格式化金额绝对残差不超过 `0.01 GBP`，超限必须查明；不能用显示四舍五入掩盖差异。
- 频次、客单价和比例的独立计算采用未格式化值，绝对误差不超过 `1e-8`；展示值只在显示精度下比较。百分比差异按比例值衡量，而非混用百分点。
- 零分母和不完整观察期返回 NULL／不可计算；真实的零回购必须保留为0，两者不能混淆。

## 5. 必测样例选择

实际执行时记录明确日期、国家、订单键和客户ID，不仅填写“已抽查”。

1. 一个完整单月＋英国；一个跨月范围＋一个实际有交易的非英国国家；一个完整季度＋全部国家，分别核对金额、订单、客户、客单价。
2. 至少一个包含多个商品的订单，验证商品多选后的订单去重；若不存在，保留查询证据并说明。
3. 缺失客户、取消、负数量、非正价格、重复与大额记录各抽查至少一例；不存在的类型以全量查询零结果为证据，不造样本。
4. 至少三个首次观测队列：较早、中间及接近数据截止月；分别检查月龄0、完整观察和不完整观察。
5. 空结果筛选、零基期和零分母：真实数据无法触发时，在独立小型测试数据中验证逻辑，标明模拟，不混入正式数据。
